【一、代码树里的密钥特征词搜索】

命中（均为公开钥匙或非密钥，不是泄漏）：
  - api.js:17                publishableKey: "wbpk_..."   ← 公开钥匙（publishable key）
  - cloud.js:19              publishableKey: "wbpk_..."   ← 同上
  - tools/verify_*.js 等     publishableKey: "wbpk_..."   ← 验证脚本复用公开钥匙
  - tools/push_to_github.py  读 GITHUB_TOKEN（从 .env/环境变量读，真值不写死代码）
  - day17/18-review 笔记     提及 wbpk_（复盘记录，非代码）
→ 真实密钥（数据库密码 / API secret / 连接串 / 私钥 / 令牌值）：0 命中

【四、.env 是否进过 Git】

【五、.env 是否被忽略（提交不出去）】
